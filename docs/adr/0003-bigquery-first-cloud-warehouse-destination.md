# Add BigQuery as the First Cloud Warehouse Destination

Data Spark will include BigQuery as the first cloud warehouse destination in the v1 destination set, alongside local and database destinations. This gives the tool a direct path to a common BI-hosted analytical store while keeping the cloud surface narrow; Snowflake, Redshift, Databricks, and other warehouse destinations can follow after the BigQuery destination proves the connector contract.
