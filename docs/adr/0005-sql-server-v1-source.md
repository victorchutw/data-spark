# Include SQL Server as a v1 Source

Data Spark will include SQL Server in the v1 source connector set, alongside local files, S3-compatible objects, PostgreSQL, MySQL, SQLite, and DuckDB. SQL Server is source-only in v1 so the product can cover common enterprise BI extraction needs without also committing to SQL Server destination write semantics and bulk loading behavior in the first version.
